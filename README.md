## 👨‍💻 About Me

Hey! I'm **Vijay Negi**, a developer passionate about building modern, responsive, and interactive web experiences.

I enjoy combining frontend engineering with creative design, smooth animations, and practical functionality to turn ideas into engaging digital products.

- 🔭 **Building:** Travel platforms, interactive websites, e-commerce experiences, and creative portfolio interfaces.
- ⚛️ **Core stack:** JavaScript, React, Next.js, and Tailwind CSS.
- 🎨 **Creative side:** Motion design, smooth scrolling, interactive layouts, and modern UI/UX.
- ⚡ **Engineering mindset:** Performance optimization, reusable components, clean code, and responsive design.
- 🔐 **Full-stack interests:** Authentication, protected routes, APIs, CRUD workflows, and PostgreSQL.
- 🌱 **Currently improving:** Scalable application architecture, animation performance, and maintainable React applications.
- 🤝 **Open to:** Learning opportunities, interesting collaborations, and meaningful web projects.

> I don't just want websites to look good. I want them to feel fast, intuitive, and memorable.
